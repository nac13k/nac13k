## 👨‍💻 About me

I'm a software engineer focused on building **scalable, observable and maintainable systems**.

Most of my work revolves around backend development, distributed architectures, cloud infrastructure and developer tooling, but I also enjoy working across the full stack when the problem requires it.

I like understanding systems end-to-end: from the user request, through APIs and asynchronous jobs, to databases, queues, infrastructure, logs, traces and metrics.

* 🛠️ Building backend systems with **Ruby on Rails, Go, PostgreSQL and Redis**
* ⚛️ Developing modern web applications with **React and TypeScript**
* ☁️ Designing and operating systems on **AWS and Google Cloud**
* 🔎 Working on **observability, distributed tracing, logs and metrics**
* 🧩 Designing **APIs, microservices and asynchronous architectures**
* ⚡ Improving **performance, reliability and developer experience**
* 🧪 Exploring better ways to automate **testing, QA and code reviews**
* 🤖 Experimenting with **LLMs, coding agents, RAG and AI-assisted development**
* 🐍 Learning more about **Python, machine learning and computer vision**
